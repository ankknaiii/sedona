# Sedona

Interactive cabin for the IGPO agentic-search trainer — elevation gain for search agents.

**Live:** https://ankknaiii.github.io/sedona/

**Trainer repo:** https://github.com/ankknaiii/igpo-agentic-search

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages builds with `GITHUB_PAGES=true` (base path `/sedona/`).
