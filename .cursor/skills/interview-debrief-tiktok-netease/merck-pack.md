# 默克经历：给外行 HR 的翻译包

问题原话：很多hr都不了解默克这段经历我们部门的定位，业务okr，进一步明确。

不要用内部黑话开场。先用对方行业的产品词，再补医药合规约束。

## 60 秒开场（先填 `profile.md` 再替换）

我在默克做的是官网和战役页这类**对客数字产品**，不是写软文。部门 OKR 是让目标用户在官网上完成指定行为：[预约/资料下载/活动报名/医生工具使用，填真实项]。我负责的部分是 [信息架构 / 内容结构 / 活动页交互 / 埋点口径，填真实项]。对接 [品牌、医学、法务、代理商、IT]。内容好不好，不看「写得专业」，看用户有没有完成行为：到达关键页、停留、点击主 CTA、表单完成、回访。医药和消费互联网差在合规审核链更长，所以我习惯先定行为指标，再写内容和路径。

## 部门定位（对外一句话）

默克官网团队 = 品牌与业务的**数字触点产品组**：把治疗领域/活动/雇主品牌变成可完成任务的页面，并在合规下把流量变成可统计的行为。

禁止开场：「我们是集团数字创新 / 全球品牌中台 / Healthcare」。对方会以为你做内部系统或纯品牌。

## OKR 怎么说

只说三级，每级一个动词 + 一个行为：

1. 公司/业务：让 [患者/HCP/求职者/活动用户] 找到并完成 [动作]
2. 部门：官网核心路径转化、战役页完成率、内容合规一次通过率
3. 个人：你负责的模块的到达、点击、完成、回访

没有官方 OKR 文档就说：「对外我按这三条对齐，内部考核名称可能不同。」不要假装有一份公开 OKR。

## 内容质量 = 用户行为（两岗通用）

对方要的原话：可量化的用户行为来定义内容质量。

| 内容动作 | 行为指标 | 别用这种空词 |
| --- | --- | --- |
| 首屏价值主张 | 主 CTA 点击率、3 秒跳出 | 高端、专业、有质感 |
| 活动/宣发页 | 预约/报名完成率、分享率、回访 | 氛围好、沉浸 |
| 说明/合规文案 | 任务完成率、报错率、客服重复问 | 写清楚了 |
| 内容模块 | 模块曝光→点击、滚动深度、搜索后回点 | 内容丰富 |
| 创作者/活动裂变 | 邀请发出数、被邀请完成数、K 因子 | 传播开了 |

口播收束：内容质量 = 用户有没有做完我们设计的下一步，以及有没有把下一步带给别人。

## 对接与角色（被问团队时）

按职责说，不按职级吹：

- 我：路径、文案结构、交互要点、验收
- 品牌/市场：卖点和战役节奏
- 医学/法务：能说什么、不能说什么
- 设计/前端或代理：视觉和实现
- 业务：活动目标和名单/渠道
- 数据：埋点和周报

被问「你是 PM 还是设计师」：按真实职责。做过需求、路径、验收、指标，就说「我在这个项目里扛的是产品侧：定义用户要完成的事，并把内容和交互收成可上线的一页。」没做过排期和资源协调，不要自称全栈 PM。

## 同一段经历，两套说法

**给 TikTok：** 我做过受约束的产品内容。先定用户下一步，再写 UI 文案，再用行为看质量。和法务/多角色对齐过，能接受「不能乱写」。

**给网易：** 官网在宣发期是转化器。我做过活动页从到达→理解卖点→完成动作→分享。游戏官网要把预约、下载、版本情报、社群接上，逻辑一样，对象换成玩家。

## 必须能答的四句事实

写进 `profile.md`，面试前背熟：

1. 部门一句话 + 你的模块边界
2. 一条你改过的路径（改前行为 / 你做了什么 / 改后行为）
3. 对接过的部门名单
4. 一个你当时**没有**的数据，以及你现在会补的埋点
